# thevault

The Corporate Heist — Solution Pipeline

### Structure
- `code/`: Core prediction pipeline scripts
  - `main.py`: End-to-end execution script
  - `data_cleaning.py`: Data parsing, normalization, and imputation
  - `feature_engineering.py`: Feature matrix construction and interactions
  - `fraud_detection.py`: Fabrication signals and duplicate resolution
  - `modeling.py`: Gradient boosting ensemble models and dev validation
  - `cycle_adjustments.py`: Insider debrief adjustments, filters, and final ranking
- `corporate_heist_data/`: Dataset and format checker
- `submission.csv`: Final ranked shortlist of top 500 candidates
- `documentation.pdf`: Final solution documentation
